✅ **Problem Summary:**   Given a 2D grid of characters and a target word, return true if the word can be found by moving only right or down, starting from any cell.
```cpp
#include <bits/stdc++.h>
using namespace std;

// DFS helper function
bool dfs(vector<vector<char>>& board, const string& word, int index, int i, int j) {
    if (index == word.size()) return true; // full word matched
    if (i >= board.size() || j >= board[0].size() || board[i][j] != word[index])
        return false;

    // Move right or down
    return dfs(board, word, index + 1, i, j + 1) || dfs(board, word, index + 1, i + 1, j);
}

// Main search function
bool exist(vector<vector<char>>& board, string word) {
    int rows = board.size(), cols = board[0].size();

    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (dfs(board, word, 0, i, j)) {
                return true;
            }
        }
    }
    return false;
}

// Main function to run tests
int main() {
    vector<vector<char>> board = {
        {'c', 'a', 't'},
        {'x', 'y', 'z'},
        {'d', 'o', 'g'}
    };

    vector<string> testWords = {"cat", "cay", "cato", "cayz", "dog", "xyz"};

    for (const string& word : testWords) {
        cout << "Word \"" << word << "\" -> "
             << (exist(board, word) ? "Found ✅" : "Not Found ❌") << endl;
    }

    return 0;
}
```

# 🧠 Graph Algorithms – Quick Interview Guide  
## ✅ How to Identify a Graph Problem

- The problem involves **nodes/vertices and edges/relationships** between them.
- You are asked about **connections, paths, cycles, or components**.
- Input could be:
  - Explicit graph representation (adjacency list/matrix).
  - Implicit graph (grid, maze, social network).
- Common question phrases:
  - "Find if a path exists between..."
  - "Count the number of connected components..."
  - "Detect cycles in the graph..."
  - "Find shortest/longest path..."
  - "Order tasks/jobs given dependencies..."

---

## 🧩 When to Use BFS, DFS, Topological Sort, etc.

| Algorithm           | When to Use                                                   |
|---------------------|---------------------------------------------------------------|
| **BFS (Breadth First Search)**   | Shortest path in unweighted graphs, level order traversal, finding connected components, cycle detection in undirected graphs, bipartite checking |
| **DFS (Depth First Search)**     | Path existence, cycle detection in directed graphs, connected components, topological sorting, backtracking |
| **Topological Sort**             | Ordering tasks with dependencies (DAG), detecting cycles in directed graphs |
| **Dijkstra’s Algorithm**         | Shortest path in weighted graphs with non-negative edges |
| **Bellman-Ford Algorithm**       | Shortest path with negative edges, cycle detection |
| **Union-Find (Disjoint Set)**   | Detecting cycles in undirected graphs, connectivity queries, Kruskal's MST |
| **Floyd-Warshall Algorithm**     | All pairs shortest path |

---

## 💡 Key Tips

- **BFS** is your go-to for shortest path in unweighted graphs or level-based problems.
- Use **DFS** when you need to explore entire components or detect cycles.
- For problems involving **task scheduling or dependency resolution**, try **Topological Sort**.
- If the graph is weighted, consider shortest path algorithms like **Dijkstra** or **Bellman-Ford**.
- For dynamic connectivity, use **Union-Find** data structure.
- Many grid or matrix problems can be interpreted as implicit graphs—apply BFS/DFS here.

## 📚 Code Snippets  
**1. BFS (Breadth First Search)**
```cpp
// BFS - Level order traversal / shortest path in unweighted graphs
void bfs(int start, vector<vector<int>>& adj, vector<bool>& visited) {
    queue<int> q;
    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int node = q.front();
        q.pop();

        // Process node here (e.g., print or record)

        for (int nbr : adj[node]) {
            if (!visited[nbr]) {
                visited[nbr] = true;
                q.push(nbr);
            }
        }
    }
}
```

**2. DFS (Depth First Search)**
```cpp
// DFS - Path existence, connected components, topological sort, cycle detection
void dfs(int node, vector<vector<int>>& adj, vector<bool>& visited) {
    visited[node] = true;
    // Process node here (e.g., print or store)

    for (int nbr : adj[node]) {
        if (!visited[nbr]) {
            dfs(nbr, adj, visited);
        }
    }
}
```

**3. Topological Sort (DFS based)**
```cpp
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

void dfs(int node, vector<int> adj[], vector<bool>& visited, stack<int>& st) {
    visited[node] = true;
    for (auto it : adj[node]) {
        if (!visited[it])
            dfs(it, adj, visited, st);
    }
    st.push(node);
}
// Usage: run dfs for all nodes and then pop stack for order

-------------------------------------------------------------------------
void topoSort(int V, vector<int> adj[]) {
    vector<bool> visited(V, false);
    stack<int> st;

    for (int i = 0; i < V; i++) {
        if (!visited[i])
            dfs(i, adj, visited, st);             //run dfs for all nodes
    }

// Pop Stack for Topo Order
    while (!st.empty()) {
        cout << st.top() << " ";
        st.pop();
    }
}
-------------------------------------------------------------------------
```

**4. Dijkstra’s Algorithm (Shortest path in weighted graphs with non-negative edges)**
| Step | Action                                            |
| ---- | ------------------------------------------------- |
| 1️⃣  | Initialize `dist[]` to `INT_MAX`, `dist[src] = 0` |
| 2️⃣  | Use min-heap: `{distance, node}`                  |
| 3️⃣  | While heap not empty, pop and relax neighbors     |
| 4️⃣  | Push updated distances back into heap             |  


**🔧 C++ Code Template**
```cpp
vector<int> dijkstra(int src, vector<vector<pair<int, int>>>& adj, int n) {
    vector<int> dist(n, INT_MAX);
    dist[src] = 0;

    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;

        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }

    return dist;
}

```

If you understand **Flood Fill**, you've understood almost **half of Graph problems on grids**.

I'll explain it in a way that makes almost every grid problem feel like a variation of the same idea.

---

# Imagine You're Holding a Bucket of Paint 🎨

Suppose you have this picture.

```text
R R R R
R G G R
R G G R
R R R R
```

Where

```
R = Red
G = Green
```

You pour **Blue paint** on this cell.

```text
R R R R
R B G R
R G G R
R R R R
```

Does only one square become blue?

No.

The paint spreads.

It flows to every connected green square.

Eventually,

```text
R R R R
R B B R
R B B R
R R R R
```

This is exactly what Flood Fill does.

---

# The Rule

When I stand on one cell,

I ask:

> "Can I spread to my neighbour?"

If YES,

I move there.

Repeat.

Repeat.

Repeat.

Until no neighbour can be painted.

That's it.


It never jumps.

It only flows to adjacent cells.

Flood Fill = Water Flow.

# Every Cell Asks One Question

Whenever you're standing here

```text
X
```

```text
      ?
   ?
 ? X ?
   ?
```

For each neighbour ask

```
Can I go there?
```

If yes

Go.

Otherwise

Ignore.

This single question is the heart of Flood Fill.

# Generic Flood Fill Template

Every flood fill algorithm looks like this:

```cpp
visit(current)

for every neighbour
{
    if(canVisit)
    {
        visit(neighbour)
    }
}
```

Literally every one.

Whether BFS or DFS.

---

# What Does "canVisit" Mean?

Depends on the problem.

Different problems change only this condition.


The traversal never changes.

# The Four Directions Trick

Instead of writing

```cpp
up
down
left
right
```

We store

```cpp
int dr[]={-1,0,1,0};
int dc[]={0,1,0,-1};
```

Think of them zipped together:

| Direction | dr | dc |
| --------- | -- | -- |
| Up        | -1 | 0  |
| Right     | 0  | 1  |
| Down      | 1  | 0  |
| Left      | 0  | -1 |

Every grid problem uses these arrays.

---

# The Universal Grid Template

You'll write this for almost every grid problem:

```cpp
for(int i=0;i<4;i++)
{
    int nr = row + dr[i];
    int nc = col + dc[i];

    if(nr>=0 &&
       nr<n &&
       nc>=0 &&
       nc<m &&
       canVisit(nr,nc))
    {
        visit(nr,nc);
    }
}
```

This becomes muscle memory after a few problems.

# The Secret That Connects Everything

Here's something many people don't realize until they've solved dozens of grid problems.

All of these are **the same algorithm**:

| Problem            | What spreads?      | Start from           | Stop when          |
| ------------------ | ------------------ | -------------------- | ------------------ |
| Flood Fill         | Paint              | Clicked cell         | Different color    |
| Number of Islands  | Exploration        | Every unvisited land | Water              |
| Surrounded Regions | Safety             | Boundary O's         | X                  |
| Rotten Oranges     | Rot                | Rotten oranges       | No fresh neighbour |
| Pacific Atlantic   | Water reachability | Ocean edges          | Height rule fails  |
| Walls and Gates    | Distance           | Gates                | Wall               |

The BFS/DFS code is almost identical.

Only these two things change:

1. **Where do you start?**
2. **What is your `canVisit()` condition?**

Everything else is the same.

---

# The One Sentence You'll Never Forget

Instead of memorizing dozens of problems, remember this:

> **Flood Fill is simply "starting from one cell, repeatedly spread to every valid neighbour until you can't spread anymore."**

Once you see a problem as **something spreading**—paint, water, fire, infection, safety, distance, or exploration—you'll immediately recognize that it's a flood fill problem and know how to solve it.
